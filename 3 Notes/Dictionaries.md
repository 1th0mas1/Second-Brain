# Dictionaries

- dictionaries differ from lists in that you access items in dictionary by a key not an index

| **Operation**   | **Big O Efficiency** |
| --------------- | -------------------- |
| `copy`          | $O(n){}$             |
| `get` item      | $O(1){}$             |
| `set` item      | $O(1){}$             |
| `delete` item   | $O(1){}$             |
| contains (`in`) | $O(1){}$             |
| `iteration`     | $O(n){}$             |

- we notice that contains for a dictionary is $O(1){}$ while for [[Lists|lists]] it is $O(n){}$
